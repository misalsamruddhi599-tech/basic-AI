# basic-AI# Basic AI Agent

## AI-Augmented Workflow Project

This project demonstrates the development of a basic AI Agent using Python
and the OpenAI API.

## Objective

The objective is to understand how an AI Agent can accept user input,
communicate with a Large Language Model, and return an AI-generated response.

## Technology Stack

- Python
- OpenAI API
- Visual Studio Code
- Git
- GitHub

## Architecture

User → Python AI Agent → OpenAI API → LLM → Response
